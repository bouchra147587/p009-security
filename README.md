# P009 — AI Model Inversion Attack and Defense

## Overview

This project explores the concept of **model inversion attacks** in machine learning and demonstrates how sensitive information can be extracted from trained models. It also implements **defense mechanisms** to mitigate such privacy risks.

The workflow includes:

* Training a simple classification model
* Simulating an attacker attempting to reconstruct sensitive data
* Applying privacy-preserving techniques to protect the model

---

##  Objectives

* Understand how machine learning models can leak sensitive information
* Implement and demonstrate a model inversion attack
* Evaluate the privacy risks associated with trained models
* Apply defense strategies to improve model security and privacy
